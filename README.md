## Project Overview

Urban FoodShare was a requirements-driven digital solution concept designed to address household food waste through expiry tracking, meal planning, surplus-food redistribution and coordination with NGOs.

The project translated the identified business problem and stakeholder needs into a structured set of functional, quality and business requirements, supported by user-centred and system-modelling artefacts.

The analysis produced **11 documented requirements** and applied requirements engineering techniques including stakeholder identification, personas, user stories, acceptance criteria, use cases, activity modelling, wireframing, input validation and risk analysis.

The end-to-end approach followed:

**Business Problem → Root-Cause Analysis → Stakeholder Needs → Requirements → User Stories & Acceptance Criteria → Use Cases → Process Modelling → Wireframe → Validation & Risk Analysis**
